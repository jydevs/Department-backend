# Panel de administración (fase visual)

El panel de administración vive por ahora en `Department-frontend` (rutas `/admin`, ver `docs/ADMIN.md` allí) y **no consume la API todavía**:
usa datos simulados. Esta rama del backend no modifica endpoints; solo deja constancia de que, al conectar el panel,
se consumirá `/api/v1/admin/*` según `docs/API.md` y `docs/openapi.json` .
